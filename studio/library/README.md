# NoDAW Studio PRO sound library (v1, drums)

Royalty-free drum one-shots with per-sample licence, author and attribution, a Mongoose/Express API,
a static `sounds.json` for the serverless demo, and an `<audio>` preview page.

## Rules

Every sound must have a licence that allows redistribution inside a paid app: CC0, or CC BY with the
attribution recorded per sample. Rejected: NC, SA, ND, Sampling+, GPL, "free for personal use" and
"royalty-free but no redistribution" EULAs, and anything unknown. There is no external licence-check
API: the licence comes from the source's own metadata (repo LICENSE and GitHub API `spdx_id`, archive.org
`licenseurl`, Freesound API `license`) and `src/licenses.mjs` checks it against an allowlist. Unknown is
rejected. `src/validate.mjs` enforces the rest (attribution text, file hash, one-shot length, duplicates).

## Layout

- `taxonomy/` 24 genres, 70 categories (`taxonomy.json` is generated)
- `ingest/` `synth_firstparty.py` (CC0, generated), `github_sfz.py` (Karoryfer CC0 kits), `archive_org.py`, `freesound.py` (env key)
- `data/records/*.json` per-source metadata; `audio/` FLAC files; `sounds.json` + `ATTRIBUTIONS.md` generated by `npm run build`
- `src/` schema, repo layer (JSON and Mongo), Express server; `preview/index.html`

## Use

```
npm install
npm run build      # merge records, validate, write sounds.json + ATTRIBUTIONS.md
npm run validate   # re-check sounds.json and files
npm test           # node tests; python test/test_ingest.py for the ingesters
npm run serve      # http://localhost:4177/preview/  and  /api/sounds?tag=kick&genre=modern-house
```

Backends (`SOUNDS_BACKEND`): `json` (default, no database), `memory` (mongodb-memory-server), `mongo`
(`MONGODB_URI`, seeded from sounds.json; `npm run seed` seeds explicitly). Free MongoDB Atlas M0
(512 MB) is not required: the metadata is about 350 KB. Audio never goes in Mongo; host files in this repo,
static hosting, or a Hugging Face dataset.

API: `GET /api/sounds?tag=&genre=&type=&category=&q=&license=&limit=&offset=`, `/api/sounds/:id`,
`/api/taxonomy`, `/api/facets`, `/api/health`. Genre accepts aliases (`modern-house` resolves to `house`).

Static demo: serve `studio/library/` as static files and open `preview/index.html`; it falls back to
`sounds.json` when `/api/health` is absent.

## Freesound

Set `FREESOUND_API_KEY` to enable `ingest/freesound.py` (CC0 and CC BY only). Freesound's API terms are
for non-commercial use unless agreed otherwise, so get clearance before shipping anything fetched that way.

## CI

`ci/sound-library.yml` is the workflow (weekly cron, no secrets needed). Copy it to
`.github/workflows/sound-library.yml` to enable it; it sits here because the token used to push this
branch cannot create workflow files.
